========================================================
  GENERADOR DE PDC - INICIO RÁPIDO CON PYTHON + PYTORCH
========================================================

COMO USAR:
1. Haz doble clic en INICIAR.bat
2. Se abrirá una consola negra (el servidor Python)
3. Se abrirá automáticamente tu navegador en:
   http://localhost:5000/
4. Cuando termines, ejecuta DETENER.bat para apagar el servidor

NOTAS:
- La consola negra debe permanecer abierta mientras uses el proyecto.
- Si cierras la consola, el servidor se detiene y el HTML
  ya no podrá comunicarse con Python/PyTorch.
- Primer uso: puede tardar unos segundos en iniciar PyTorch.

ARCHIVOS CREADOS:
- backend/app.py          (Servidor Flask + PyTorch)
- backend/venv/           (Entorno virtual Python)
- INICIAR.bat             (Iniciar todo con 1 clic)
- DETENER.bat             (Apagar servidor)
